# Smart Water Leakage Detection and Monitoring System

EVS college assignment – a frontend-only prototype that simulates detecting water leakage in a building.

## Problem
Water leakage and wastage in buildings.

## Features
- Live dashboard with simulated flow and moisture sensors
- 5 locations: Kitchen, Bathroom, Utility Room, Water Tank, Main Pipeline
- Simulate Normal Usage / Simulate Water Leakage / Reset
- Leak alert, highlighted location, water wastage counter
- Water consumption chart (HTML Canvas)

## Tech
HTML, CSS, JavaScript only. No backend, database, login, AI/ML or real IoT hardware. Sensor data is simulated.

## Run
Open `index.html` in any browser.

## Environmental Benefits
Reduces wastage, detects leaks early, saves water, lowers bills, supports sustainable water management.
